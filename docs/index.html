着信通知 (FCM) について。 通話の着信通知は Firebase Cloud Messaging (FCM) で届きます。GrapheneOS では Sandboxed Google Play (Apps アプリから Google Play サービスをインストール) が有効でないと着信通知を受け取れません。 Sandboxed Google Play は同じユーザープロファイルにインストールし、Ghostflow に通知の権限を許可してください。

GrapheneOS での導入手順

  1. この端末の Vanadium (標準ブラウザ) で上の「APK をダウンロード」を開き、APK を保存します。
  2. ダウンロード完了の通知、または Vanadium のダウンロード一覧から APK を開きます。
  3. 初回は「不明なアプリのインストール」の確認が出ます。Vanadium に対して 「このソースからのインストールを許可」 を有効にします。
  4. 「インストール」を選びます。既にインストール済みなら、同じ署名の APK として上書き更新され、データは保持されます。
  5. インストール後、下の「署名 fingerprint の照合」で改ざんされていないことを確認できます。

対象 ABI は arm64-v8a (64bit ARM) のみです。他の ABI の端末にはインストールできません。

更新方法 (3 種)

1. Obtainium (推奨)

「Obtainium に追加」を押すと、Obtainium がこの配信 repo の GitHub Releases を監視し、新しいバージョンを通知・更新できます。 Obtainium が未導入なら、先に Obtainium 自体を導入してください (Obtainium は本ページからは配布しません)。

2. このページ

このページを開き直し、「APK をダウンロード」から新しい APK を入れ直します。同じ署名なので上書き更新になります。

3. アプリ内「アップデートを確認」

Ghostflow のマイページにある 「アップデートを確認」 を押すと、この latest.json を 1 回だけ読み、 新しいバージョンがあれば「ダウンロード」ボタンでブラウザに APK の取得先を渡します。自動チェックや起動時の確認はしません。

署名 fingerprint の照合

ダウンロードした APK の署名者 (signer) 証明書の SHA-256 が、上に表示されている値と一致することを確認します。 Android SDK build-tools の apksigner を使います。

apksigner verify --print-certs ghostflow-<versionName>-<versionCode>-arm64-v8a.apk
# "Signer #1 certificate SHA-256 digest:" の値と、このページの「署名 (signer) SHA-256」を比較する

APK ファイル自体の SHA-256 は sha256sum (macOS は shasum -a 256) で計算し、「SHA-256」の値と比較できます。 Release には同名の .sha256 ファイルも添付されています。

値が一致しない場合はインストールしないでください。

配信の仕組み

  • APK は GitHub Releases (v<versionName>-<versionCode> tag) に添付され、このページは同じ repo の GitHub Pages から配信されます。
  • このページの JavaScript は同一 origin の latest.json (schemaVersion 1) だけを読みます。外部 script、フォント、計測は使いません。
